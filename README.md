# 🚗 Vehicle Speed Monitoring System using MATLAB

## 📌 Overview

A MATLAB-based vehicle speed monitoring system designed to calculate
and monitor vehicle speed and identify speed-limit violations.

## 🎯 Objectives

- Monitor vehicle speed
- Compare speed with a predefined speed limit
- Detect overspeeding
- Generate speed status/alerts
- Demonstrate automotive software concepts using MATLAB

## 🛠️ Technologies Used

- MATLAB
- MATLAB Functions
- Git & GitHub

## ⚙️ How It Works

The system receives vehicle speed data and processes it using MATLAB.
The calculated speed is compared with the defined speed limit.

If the vehicle exceeds the limit, the system identifies an
overspeed condition.
